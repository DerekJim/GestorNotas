# Gestor de Notas Académicas

Este proyecto fue desarrollado por **Derek Stuard Jiménez Deleón** como parte del curso de Algoritmos.

## Reflexión Personal

**¿Qué aprendí con este proyecto?**  
Aprendí a usar estructuras de datos como listas, pilas y colas dentro de un programa real. También comprendí cómo dividir el código en funciones y cómo hacer que un menú controle todo el sistema.

**¿Qué fue lo más desafiante de resolver?**  
Lo más difícil fue entender cómo aplicar los algoritmos de ordenamiento y la búsqueda binaria, pero con práctica y repeticiones logré entender su funcionamiento.

**¿Qué mejoraría si tuviera más tiempo?**  
Me gustaría agregar una interfaz gráfica o guardar los datos en un archivo para que no se pierdan al cerrar el programa.
